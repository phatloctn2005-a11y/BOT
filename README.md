# Fate/Grand Order AI Bot

このプロジェクトはAIに沿ってゲームが自動化され、コンピュータビジョンと強化学習が含まれているシステムです。

# Overview

このプロジェクトは強化学習やYOLOの物体の発見の仕方の技術を通して、Fate/Grand Orderのプレイの仕方の自動化の仕方を探求しているプロジェクトです。

# Architecture

1.画面の撮影:現在時間に沿って画面を連続に撮影します。  /n
2.物体の発見:敵、人物、スキル、カードを発見します。
3.状態の修理:発見された結果から観察に変えます。
4.決定の出し方:各ルールかPPOの動き方に沿って行動を選びます。
5.ゲームの制御:エミュレーターを通して、行動します。
